# Kotlin & Android Studio

Examples of completed Android Studio projects. Require Android device or emulator to run.

* Jordan Beirne's Portfolio - An app which combines five projects into one navigable app as fragments.
* Rank.it - An interactive social app which allows users to voice their opinion by voting among various topics and creating new topics. I was responsible for backend development, creating db.kt, as well as tracking each user's vote limit via SharedPreferences.
